# Wireframe da Interface — PREDICTA

## 1. Apresentação

O wireframe do PREDICTA apresenta a proposta visual da interface de interação entre os usuários e o assistente inteligente.

O protótipo apresenta a estrutura visual e a organização das principais interfaces da plataforma, demonstrando como engenheiros de manutenção e operadores do CCO poderão interagir com o assistente e acessar informações para apoiar a tomada de decisão

## 2. Objetivo

Demonstrar a organização e a experiência de uso previstas para o PREDICTA, estabelecendo uma referência visual para a futura implementação da interface utilizando Gradio.

O wireframe representa uma proposta de interface e não uma aplicação funcional.
